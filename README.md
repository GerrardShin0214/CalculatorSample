# 막타 키친 (한밤의 주방 수비대) · Unity 모바일 프로토타입

사장님이 잠든 자정, **의인화된 주방 식구(식기와 재료)** 가 깨어나 주방에 몰래 들어오는 **도둑 동물들**을 막는다(타워 디펜스).
동물들은 조리대에서 낚아챈 음식을 물고 창고로 달아나는데, **막타를 친 식구가 떨어뜨린 음식을 제 방식대로 손질**해 둔다.
아침이면 사장님은 영문도 모른 채 그 재료로 식당을 연다(식당 경영). 그래서 **무엇으로 막타를 쳤느냐가 내일의 메뉴를 정한다.**

- 기획서: [주방 디펜스 — 게임 기획서 v0.1](https://claude.ai/artifact/DQ9BudzjnNZ5uYj5TNPtB9)
- 이 저장소는 기획서의 **"첫 프로토타입 범위"** 를 그대로 구현한 회색 박스(색 박스) 빌드다.
  목적은 하나, **막타를 노리는 게 재밌는지** 확인하는 것.
- 세로 화면 · 한 손 플레이 · Android/iOS 대상. 아트·사운드 없이 도형과 글자로만 그린다.
- 기획서와 달라진 점: 몬스터를 요리하는 대신 **도둑 동물이 물고 온 음식을 손질**한다(벌레는 파리만).
  스테이지(밤) 사이마다 이야기를 한 토막씩 보여 준다. 자세한 내용은 아래 [세계관과 이야기](#세계관과-이야기).

## 세계관과 이야기

할머니가 40년 꾸려 온 골목 식당을 손주인 **사장님**이 다시 열었다. 닷새 뒤엔 **미식 평론가**가 온다.
쥐 두목 **찍찍대왕**은 할머니의 **손맛 비법 노트**를 노리고 밤마다 **찍찍단**을 보낸다.
창고가 털릴 때마다 주방이 어지럽혀져 **위생**이 깎이고, 0이 되면 영업 정지. 평론가가 오는 날까지 가게를 지키는 것이 시즌의 목표다.

| 주방 식구 (타워) | 원래 기구 | 막타 = 손질 방식 |
|---|---|---|
| 칼 삼형제 | 식칼 거치대 | 썰기 (치즈 조각, 고구마 채, 생선 살) |
| 불판 아저씨 | 그릴 | 구이 (구운 치즈, 군고구마, 구운 생선) |
| 냉동고 언니 | 냉동고 | 얼리기 (보존 6일, 대체 시 -30%) |
| 솥할매 | 가마솥 | 삶기 (체력 25% 이하 확정, 찐 고구마, 조린 생선) |
| 꼬마 양파 양양이 | 재료 | 이야기의 막내(겁 많고 잘 우는 새내기 재료) |

| 찍찍단 (적) | 처음 나오는 밤 | 특징 | 물고 오는 음식 |
|---|---|---|---|
| 생쥐 떼 | 0일 밤 | 쫓겨나면 꼬마 생쥐 2마리가 흩어짐 | 치즈 |
| 파리 떼 | 1일 밤 | 윙윙 소리에 근처 식구가 느려짐 | 없음 (그냥 귀찮음) |
| 멧돼지 | 2일 밤 | 직선에서 돌진, 얼리면 멈춤 | 고구마 |
| 너구리 | 3일 밤 | 털이 두꺼워 칼에 강하고 열에 약함 | 생선 |

| 스테이지 | 이야기 | 깨야 하는 이유 |
|---|---|---|
| 프롤로그 / 0일 밤 | 개업 전야 | 첫 습격. 창고를 지키고 첫 재료를 손질 |
| 1일 밤 | 윙윙 정찰대 | 찍찍단이 파리 떼를 불렀다 |
| 2일 밤 | 뒷산의 손님 | 고구마 냄새를 맡은 멧돼지가 내려왔다 |
| 3일 밤 | 털보 너구리 | 찍찍대왕이 힘센 너구리를 보냈다 |
| 4일 밤 | 찍찍대왕의 총공격 | 평론가 방문 전날, 찍찍단 전원 출동 |
| 5일 낮 | 엔딩 | 평론가 평가(S/A/B/C)에 따라 다른 엔딩, 위생 0이면 배드 엔딩 |

장면은 대사를 한 줄씩 탭해서 넘기고(건너뛰기 가능), 마지막에 그날 밤의 목표를 보여 준다.
예약은 이미 등장한 동물의 음식으로만 들어온다(1~2일차 치즈, 3일차부터 고구마, 4일차부터 생선).
대사는 `Scripts/Core/Story.cs` 한 파일에 모여 있다.

## 바로 실행하기

1. **Unity 6000.3.5f2** 로 연다. (`ProjectSettings/ProjectVersion.txt`)
   - Unity Hub → Add → 이 폴더 선택. 더 새 버전으로 열어도 자동 업그레이드된다.
2. `Assets/KitchenDefense/Scenes/Main.unity` 를 연다. (메뉴 **Kitchen Defense → 메인 씬 열기**)
3. Game 뷰 해상도를 세로로 맞춘다. 예: `1080x1920 Portrait` 또는 `1080x2400`.
4. **Play**. 씬이 비어 있어도 `GameBootstrap`이 카메라·UI·보드를 전부 코드로 만든다.

> 에디터에서 처음부터 다시 하려면 메뉴 **Kitchen Defense → 세이브 데이터 지우기**.

## 휴대폰에서 실행하기

### Android
1. Unity Hub에서 해당 에디터에 **Android Build Support** (OpenJDK, Android SDK & NDK 포함) 모듈 추가.
2. File → Build Settings → **Android** → Switch Platform.
3. 휴대폰 개발자 옵션의 USB 디버깅을 켜고 연결 → **Build And Run**.

세로 고정, 패키지 이름 `com.gerrardshin.kitchendefense`, IL2CPP + ARMv7/ARM64, 최소 API 25가
`ProjectSettings`에 이미 들어 있다. 설정이 바뀌었으면 메뉴 **Kitchen Defense → 모바일 빌드 설정 적용**으로 되돌린다.

### iOS
Mac에서 **iOS Build Support** 모듈을 추가하고 iOS로 Switch Platform → Build → 나온 Xcode 프로젝트에서
서명(Team)을 고르고 실기기로 실행한다.

## 조작법

| 상황 | 조작 |
|---|---|
| 식구 배치 | 길 옆 빈 칸을 탭 → 아래 바에서 식구 선택 (또는 식구를 먼저 고르고 초록 칸 탭) |
| 솥할매 | 길 위 칸에만 배치 (함정) |
| 배치한 식구 | 탭하면 **약불**(피해 절반) / **강화**(화력, 오늘 밤만) / **이동** / **회수** |
| 웨이브 | 웨이브 사이에는 멈춘다. **웨이브 시작** 버튼으로 진행. 준비 시간에는 이동·회수가 무료 |
| 막타 예상 아이콘 | 동물 체력바 옆 원 = 지금 상태로 막타를 칠 식구. 예약에 필요한 동물은 크게 표시되고 테두리가 **초록**(원하는 재료가 나옴)/**빨강**(다른 재료가 나옴) |
| 체력바 | 빨간색(25% 이하) = 솥할매가 확정으로 삶는 구간 |
| 속도·일시정지 | 1배속/2배속, 오른쪽 위 `II`. 안드로이드 뒤로가기 = 일시정지 |
| 이어하기 | 앱을 나가는 순간 저장된다(웨이브 도중 동물 위치까지). 돌아오면 멈춘 상태로 이어짐 |

## 한 시즌의 흐름 (5일)

```
프롤로그 → 개업 전야(첫 예약 메모) → 0일 밤 → 1일 낮 → [이야기] 1일 밤 → … → [이야기] 4일 밤 → 5일 낮 → 엔딩 → 시즌 평가
낮 = 메뉴 짜기(최대 3개) → 자동 영업 결과 → 상점(매일 무작위 4개 + 대청소) → 마감(창고 정리, 냉장고 예약 메모 수락/거절)
```

- **막타 = 조리법**: 칼 삼형제=썰기, 불판 아저씨=구이, 냉동고 언니=얼리기, 솥할매=삶기. 표에 없는 조합(삶은 치즈)은 잡재료(오늘의 백반).
- **얼린 재료**: 보존 6일. 낮에 같은 음식의 다른 재료로 대체할 수 있지만 판매가 -30% (얼린 고구마 → 군고구마 등).
- **예약**: 보상은 일반 판매의 2배 이상, 받고 못 지키면 평판 -1. 받은 예약이 그날 밤의 두 번째 목표가 된다.
- **창고 털림**: 창고에 닿은 동물은 가장 비싼 재료를 훔쳐 가고 위생 -1. 위생 10이 0이 되면 영업 정지(배드 엔딩).
- **평판**: 오르면 손님 수·판매가가 오르지만 냄새가 퍼져 찍찍단도 거세진다.

## 기획서 대비 구현 범위

| 구분 | 이번 프로토타입에 포함 | 다음 단계로 미룸 (기획서 그대로) |
|---|---|---|
| 맵 | 주방 1개, 고정 경로 1개 (가로 7칸 x 10칸) | 맵 여러 개, 미로형 |
| 조리기구 | 칼 삼형제(식칼), 불판 아저씨(그릴), 냉동고 언니, 솥할매(가마솥) | 훈연기, 튀김기, 강화 트리 |
| 적 | 생쥐 떼(흩어짐), 파리 떼(윙윙), 멧돼지(돌진), 너구리(칼 저항·열 약점) | 보스(찍찍대왕 본인), 새 지역의 동물 |
| 요리 | 레시피 8개 | 익힘 정도 시스템 |
| 낮 | 메뉴 짜기, 결과 화면, 상점(+수리) | 손님 유형, 아침 소식 카드, 영업 연출 |
| 진행 | 5일 시즌, 예약 하루 1건, 시즌 점수/등급 | 미끼, 도감, 메타 해금 |
| UI | 막타 예상 아이콘, 약불 모드, 세로 한 손 조작, 즉시 저장, 스테이지 사이 이야기 | 아트, 사운드 |

기획서에 수치가 없던 부분(동물 체력, 기구 피해, 화력 등)은 프로토타입용 초기값이다.
전부 `GameData.cs`의 `Balance`와 데이터 표에 모여 있어 숫자만 바꿔 다시 테스트할 수 있다.

## 픽셀 이펙트 (pixelfx)

[pixelfx](https://github.com/patch-gg/pixelfx)(MIT)의 픽셀 아트 효과 8개가 `Assets/KitchenDefense/Resources/PixelFx/`에 들어 있다.
시트(PNG + JSON)가 있으면 게임이 자동으로 쓰고, 없으면 도형 연출로 대신한다.

| 게임 연출 | pixelfx 효과 |
|---|---|
| 칼 삼형제 타격 | `impacts/hit-spark` |
| 동물을 쫓아냄 | `spawn/poof` |
| 냉동 막타 | `ice/snowflake-burst` |
| 솥할매 삶기 | `water/splash` |
| 예약 재료 획득 | `pickups/collect-burst` |
| 창고가 털림 (위생 -1) | `ui/heart-lost` |
| 화상 중인 동물 (반복) | `status/burning` |
| 감속 중인 동물 (반복) | `status/frozen` |

다시 뽑는 법 (Node.js 18 이상):

```
git clone https://github.com/patch-gg/pixelfx ../pixelfx
node Tools/pixelfx/import-pixelfx.mjs ../pixelfx
```

스크립트가 pixelfx의 `tools/render.mjs --sheet`로 위 8개를 뽑아 폴더에 복사하고, MIT 라이선스와 NOTICE를
`pixelfx-LICENSE.txt`로 같이 넣는다(게임과 함께 배포됨). Unity로 돌아가면 `Editor/PixelFxImport.cs`가
점 필터·무압축으로 임포트한다. 새로 생긴 `.meta` 파일도 함께 커밋할 것.
다른 효과로 바꾸려면 스크립트의 `EFFECTS`와 `PixelFxLibrary.cs`의 이름을 같이 바꾸면 된다.
pixelfx의 `gallery/fonts` 글꼴은 MIT가 아니므로 쓰지 않는다.

## 테스트

- **Unity**: Window → General → **Test Runner** → EditMode → Run All.
- **Unity 없이**: .NET 8 SDK가 있으면
  ```
  dotnet test Tools/CoreTests/CoreTests.csproj
  ```
  막타 규칙, 솥할매 25% 기준, 냉동 대체 -30%, 예약 성공/실패, 상함, 창고 초과, 상점,
  **막타 예상이 실제 막타와 정확히 일치하는지**, 이야기와 동물 등장 순서가 맞는지,
  그리고 봇이 시즌 전체를 플레이하는 테스트(결정론·난이도)가 들어 있다.
- 밸런스 리포트: `SeasonSimulationTests.BalanceReport`(Explicit)를 실행하면 기구 수별 실패율·누수·점수가 출력된다.
  현재 값 기준으로 식구 2명만 쓰면 대부분 영업 정지되고, 무난한 배치는 시즌당 창고 털림 5회 안팎으로 버틴다.
  막타를 신경 쓰지 않는 봇의 예약 성공은 5건 중 2건 정도라서, 막타를 계획하면 점수가 크게 오른다.

## 플레이테스트에서 볼 것 (기획서)

1. 예약 재료를 얻으려고 배치를 바꾸는가, 아니면 딜만 올리는가?
2. 막타 조절이 퍼즐로 느껴지는가, 귀찮은 일로 느껴지는가?
3. 낮이 템포를 끊지 않는가? (낮 평균 1분 이내)
